# Managed PostgreSQL clients

Generated by `npm run desktop:prepare` from pinned official PostgreSQL source
archives. The build includes pg_dump, pg_restore, psql, required non-system shared
libraries and their notices for each supported major. No server is installed/run.
The application selects these resources offline; end users never build/install them.

Generated files are not committed. The generated manifest is embedded in Rust,
and the runtime verifies packaged file hashes against that embedded manifest.
Release packaging must run the preparer and sign the complete application bundle.
