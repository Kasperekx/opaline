# Provider artwork

## PostgreSQL

`postgresql.svg` is the unmodified three-color Slonik artwork published by the
[official PostgreSQL wiki](https://wiki.postgresql.org/wiki/Logo).

Source: https://wiki.postgresql.org/images/a/a4/PostgreSQL_logo.3colors.svg

Postgres, PostgreSQL, and the Slonik Logo are trademarks or registered trademarks
of the PostgreSQL Community Association of Canada. This third-party artwork has
its own usage terms, independent of Opaline's licensing. Use is subject to the
[PostgreSQL Trademark Policy](https://www.postgresql.org/about/policies/trademarks/).
Preserve the approved artwork and colors; do not merge it into Opaline's mark or
imply PostgreSQL sponsorship, affiliation, or endorsement. It is used here to
identify the supported database provider.

## SQLite

`sqlite.svg` extracts the database and feather from the SVG banner currently
published on SQLite's website: `defs`, `path21`, `g37`, and `path55`. The text and
white backdrop were removed, and the viewport is `56 60 43 49`. Original symbol
paths, fill colors, and the database gradient are unchanged.

Source: https://sqlite.org/images/sqlite370_banner.svg

SQLite's deliverable code and documentation are
[dedicated to the public domain](https://sqlite.org/copyright.html). The logo
appears in its documentation; use identifies SQLite, not endorsement of Opaline.

## MySQL (not included)

The [official download policy](https://www.mysql.com/about/legal/logos.html)
requires written permission for the original MySQL logo. Conditional-use
"Powered by" / "Includes" logos would imply functionality not yet implemented.
Use the MySQL name with a neutral database icon until an appropriate permission
or approved usage is established.
